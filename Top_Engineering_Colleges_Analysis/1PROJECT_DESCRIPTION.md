# 📊 Top Engineering Colleges – Placement Analysis Dashboard (Power BI)

An interactive **Power BI dashboard** built to visualize and compare placement trends, average packages, and higher studies statistics of top engineering institutes in India, using data extracted from **NIRF (National Institutional Ranking Framework)** reports for academic years **2017–2023**.

---

### 📌 Key Insights Delivered

| 🔍 **Insight**                               | 📋 **Description**                                                                |
| -------------------------------------------- | --------------------------------------------------------------------------------- |
| 🎓 Top Colleges by Placement & Research      | Identify institutions with the highest placement figures and research engagement. |
| 💼 Program-Wise Average Package Analysis     | Compare average salaries across UG, PG, UG-INT, and PG-INT programs.              |
| 📈 Year-Wise Salary Trends                   | Visualize how average packages have changed from 2017 to 2023.                    |
| 📚 Placement vs. Higher Studies Distribution | Analyze how many students opted for placements vs. higher studies.                |
| 📍 College Type & Program Breakdown           | Explore detailed institute-level metrics using interactive tooltips and slicers.  |
| 🎓 Higher Studies Visuals                    | Understand trends in higher education uptake through pie charts and bar graphs.   |

---

## 🧰 Built With

* **Power BI Desktop** – for dashboard design and interactive visuals
* **DAX** – for calculated metrics like average package per year/program
* **Custom Tooltips** – for detailed college-level insights
* **Slicers** – to filter by year, program, or institution dynamically
