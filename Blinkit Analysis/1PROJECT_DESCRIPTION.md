# 📊 Blinkit Sales Analysis Dashboard

Welcome to the **Blinkit Sales Analysis Dashboard** — a sleek, interactive business intelligence solution built using **Power BI** to analyze sales patterns, product performance, and outlet effectiveness for Blinkit, India’s last-minute grocery delivery platform.

## 🚀 Project Overview

This project delivers a multi-dimensional analysis of Blinkit's operations, enabling stakeholders to explore and understand:

* Sales performance across years
* Outlet efficiency based on size, location, and type
* Product category trends and popularity
* Customer feedback via average ratings
* Fat content distribution across items and outlets

## 🧩 Dashboard Features

* **Filter Panel**: Slicers for outlet location, size, type, item fat content, and item type
* **Interactive Visuals**:

  * Trend charts, bar graphs, pie charts, and KPI indicators
  * Tabs to switch between key sales metrics
* **Modular Design**: Easy to scale or adapt for other datasets or companies

---

## 🛠️ Tech Stack

* **Power BI** for dashboard development
* **DAX** for calculated measures
* **Excel/CSV** (or database source) as backend data

---

## 💡 Use Cases

* Identify top-performing outlets and regions
* Analyze consumer preferences and product demand
* Guide supply chain and inventory decisions
* Monitor and improve customer satisfaction metrics
