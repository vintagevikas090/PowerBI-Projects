# 🏥 Hospitality Analysis Dashboard | Power BI

A fully interactive **Power BI dashboard** built to analyze hospital waiting list trends and patient care distribution across time, age, and specialties. This project aims to simplify complex healthcare data into meaningful, visually intuitive insights to support decision-making in the healthcare sector.

---

## 🔍 Key Features

* 📅 **Time-Based Comparison**
  Analyze how hospital waiting lists evolve over time, year-over-year.

* ⏳ **Waiting Time Bands**
  Segment patients based on how long they’ve waited and explore delays across age groups.

* 🌀 **Case Type Distribution**
  Visualize the proportion of outpatient, inpatient, and day cases.

* 📈 **Monthly Trend Analysis**
  Track patient volume and trends month-by-month for various care types.

* 🏥 **Top Specialties Overview**
  Identify key medical specialties with the highest waitlist volumes.

* 🎛️ **Interactive Filtering**
  Dynamic filters for custom views based on date range, category, and specialty.

---


## 💼 Use Cases

* For **Hospital Administrators** to monitor patient flow and waiting periods.
* For **Healthcare Analysts** to identify inefficiencies and trends.
* For **Public Health Officials** to plan resource allocation.
* For **Students & Learners** practicing Power BI with real-world datasets.
